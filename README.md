# SOBRE O PROJETO


# Vitrine de Produtos 

# Descrição: 

O projeto "Vitrine de Produtos" é uma aplicação web desenvolvida para exibir e filtrar produtos 
consumindo  dados  de uma API. 

Ele simula uma loja virtual simples, focando no front-end, com usabilidade, organização e 
responsividade. 

# Front-End 

Interface web desenvolvida com ReactJS para consumo da API  

# Back-End 

API  para gerenciamento de produtos, utilizando C# com ASP.NET Core. 
Funcionalidades: 

# Front-End 

• Exibição de produtos da API 

• Filtro por categoria dos produtos 

• Campo de busca  

• Carrossel com destaques e banners promocionais 

• Seção de pesquisa produtos por Liga/ competição 

• Layout responsivo com uso de CSS personalizado 

• Navegação entre rotas com React Router 

• estoque nos produtos 

• atualizacao de estoque 

• produtos sem estoque nao pode ser visto 

• tela login com senha 
( dmin e 1234 )
 # Back-End 


• CRUD de produtos (Get, Post, Update, Delete) 

• - Integração com o banco de dados PostgreSQL 

• - Endpoints para manipulação dos dados 

# Tecnologias utilizadas: 

• C#  

• Entity Framework Core  


• Entity Framework Core PostgreSQL 

• Swagger
